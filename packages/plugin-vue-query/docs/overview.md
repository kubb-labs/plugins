# Vue Query

The Vue Query plugin generates TanStack Query helpers for Vue from your OpenAPI spec: `queryOptions` factories with their cache keys, plus a key for each mutation. Set `hooks: true` to also get `useQuery` and `useMutation` composables that take reactive parameters.

The plugin ships no HTTP client. Each helper calls a function generated by a client plugin.

## Setup

- Add `@kubb/plugin-ts`, or `pluginZod({ inferred: 'codec' })` for codec types. The codec types need `zod` v4 in the app.
- Add one client plugin: `@kubb/plugin-fetch`, `@kubb/plugin-axios`, or `@kubb/plugin-client`. Leave `sdk` unset on it.
- Install `@tanstack/vue-query` 5.41 or a later v5 release and `vue` 3.3 or later in the app that uses the generated code.
- Set the base URL, auth, and validation on the client plugin, not here. With `@kubb/plugin-client`, your client module sets the base URL and auth.

## Options worth knowing

| Option              | What it does                                                                                                                 |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `client`            | Picks `'fetch'`, `'axios'`, or `'client'` when more than one client plugin is registered. A single one is detected.          |
| `hooks`             | Adds the `use*` composables on top of the factories. `infinite` needs it.                                                    |
| `query`, `mutation` | Set which HTTP methods become queries (`GET`, `QUERY`) and mutations (`POST`, `PUT`, `PATCH`, `DELETE`). `false` skips them. |
| `infinite`          | Adds infinite queries to the operations that take the query parameter in `infinite.queryParam`, `'id'` by default.           |

See [Options](https://kubb.dev/extensions/kubb-labs/plugin-vue-query/options) for every option and its default.

## Example

The config below generates `useQuery` and `useMutation` composables that call the Fetch client.

```typescript [kubb.config.ts]
import { defineConfig } from 'kubb/config'
import { adapterOas } from '@kubb/adapter-oas'
import { pluginTs } from '@kubb/plugin-ts'
import { pluginFetch } from '@kubb/plugin-fetch'
import { pluginVueQuery } from '@kubb/plugin-vue-query'

export default defineConfig({
  input: './petStore.yaml',
  output: { path: './src/gen' },
  adapter: adapterOas({ integerType: 'number' }),
  plugins: [
    pluginTs(),
    pluginFetch(),
    pluginVueQuery({ hooks: true }),
  ],
})
```
