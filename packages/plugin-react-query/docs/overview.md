# React Query

The React Query plugin generates TanStack Query helpers for React from your OpenAPI spec: `queryOptions` and `mutationOptions` factories with their cache keys. Set `hooks: true` to also get `useQuery` and `useMutation` hooks, with suspense and infinite variants on request.

The plugin ships no HTTP client. Each helper calls a function generated by a client plugin.

## Setup

- Add `@kubb/plugin-ts`, or `pluginZod({ inferred: 'codec' })` for codec types.
- Add one client plugin: `@kubb/plugin-fetch`, `@kubb/plugin-axios`, or `@kubb/plugin-client`. Leave `sdk` unset on it.
- Install `@tanstack/react-query` 5.82 or a later v5 release in the app that uses the generated code.
- Set the base URL, auth, and validation on the client plugin, not here.

## Options worth knowing

| Option              | What it does                                                                                                                 |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `client`            | Picks `'fetch'`, `'axios'`, or `'client'` when more than one client plugin is registered. A single one is detected.          |
| `hooks`             | Adds the `use*` hooks on top of the factories. `infinite`, `suspense`, and `customOptions` need it.                          |
| `query`, `mutation` | Set which HTTP methods become queries (`GET`, `QUERY`) and mutations (`POST`, `PUT`, `PATCH`, `DELETE`). `false` skips them. |
| `infinite`          | Adds infinite queries to the operations that take the query parameter in `infinite.queryParam`, `'id'` by default.           |
| `suspense`          | `{}` adds `useSuspenseQuery` hooks.                                                                                          |
| `customOptions`     | Routes every hook through your own function that returns shared options.                                                     |

See [Options](https://kubb.dev/extensions/kubb-labs/plugin-react-query/options) for every option and its default.

## Example

The config below generates `useQuery` and `useMutation` hooks that call the Fetch client.

```typescript [kubb.config.ts]
import { defineConfig } from 'kubb/config'
import { adapterOas } from '@kubb/adapter-oas'
import { pluginTs } from '@kubb/plugin-ts'
import { pluginFetch } from '@kubb/plugin-fetch'
import { pluginReactQuery } from '@kubb/plugin-react-query'

export default defineConfig({
  input: './petStore.yaml',
  output: { path: './src/gen' },
  adapter: adapterOas({ integerType: 'number' }),
  plugins: [
    pluginTs(),
    pluginFetch(),
    pluginReactQuery({ hooks: true }),
  ],
})
```
