An exploded `form` cookie object percent-encodes its keys, so a key such as `a; admin` cannot add a cookie. A `multipart/mixed` part sends the first type of an Encoding `contentType` list such as `image/png, image/jpeg`. An API key name, a scope or an OAuth flow name with a `'` no longer breaks the generated code, and the custom client guide types `security` as `Array<Auth | Array<Auth>>`, so requirements that need several schemes typecheck.
